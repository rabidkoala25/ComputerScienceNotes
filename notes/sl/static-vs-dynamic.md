## Static Data Structures

- Defined size at compile time.
- Example: arrays (java)
- Memory allocated in contiguous blocks. 
- Less flexible, more predictable

## Dynamic Data Structures

- Size can change at runtime.
- Example: linked lists. ([[Arrays and linked lists]])
- Memory allocated as needed, often non-contiguous
- More flexible, less predictable
